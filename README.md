# 🌿 Greeden – Plant Selling Website

Greeden is a plant-selling website developed using **HTML and Tailwind CSS**. It features a clean, modern, and nature-inspired design that showcases plants and provides a simple, user-friendly browsing experience.

## 🌱 Features

- 🌿 Attractive and nature-inspired user interface
- 🪴 Plant product showcase
- 🎨 Modern styling using Tailwind CSS
- 📱 Responsive website design
- 🧭 Simple and user-friendly navigation
- 💻 Clean and structured HTML code

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **Tailwind CSS** – Styling and responsive layouts

## 🎯 Project Objective

The main objective of this project is to improve my front-end web development skills by building a plant-selling website using HTML and Tailwind CSS.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Run the Tailwind CSS build command if required.
4. Open `index.html` in your browser.
